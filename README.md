# VCNO

Video reviews of Long Beach places. Record a 15–60 second video, give a score from 0.0 to 10.0.

## Project Structure

- `src/vcno.html` — The main web app
- `docs/` — Development notes

## Setup

1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/vcno.git`
2. Open `src/vcno.html` in a browser, or deploy to a web server

## Development

To run locally:
```bash
# If you have Python 3:
python3 -m http.server 8000
```

Then open `http://localhost:8000/src/vcno.html`
